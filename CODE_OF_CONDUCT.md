# Code of Conduct

## The short version

Be kind. Be respectful. Assume good intentions. If someone makes a mistake, help them learn instead of tearing them down.

## The longer version

This project is open to everyone regardless of experience level, background, identity, or where they're from. We're building Zakera to make AI tools more accessible — that mission starts with how we treat each other.

**Expected behavior:**
- Be welcoming to newcomers
- Give constructive feedback
- Respect differing viewpoints
- Accept responsibility for your mistakes and learn from them

**Not acceptable:**
- Harassment, insults, or personal attacks
- Trolling or deliberately inflammatory comments
- Publishing others' private information
- Any behavior that would make someone feel unwelcome

## Enforcement

If someone is behaving badly, report it by emailing the maintainer directly. Reports will be reviewed and handled confidentially. Anyone who violates this code of conduct may be temporarily or permanently banned from contributing.
