## Overview

Zakera provides a comprehensive, enterprise-grade authentication and authorization system with multiple authentication methods, fine-grained access control, and advanced security features.

### Key Features

✅ **Multiple Authentication Methods**
- Username/Password (JWT)
- OAuth2 (Google, GitHub, Microsoft)
- API Keys
- Multi-Factor Authentication (MFA)

✅ **Role-Based Access Control (RBAC)**
- 6 predefined roles
- 20+ granular permissions
- Hierarchical role structure
- Dynamic permission checking

✅ **Security Features**
- Strong password policies
- Brute-force protection
- Rate limiting
- Session management
- Audit logging
- Security headers

✅ **Token Management**
- Short-lived access tokens (15 min)
- Long-lived refresh tokens (7 days)
- Token rotation
- Secure revocation

## Authentication Methods

### 1. Username/Password Authentication

#### Registration Flow

```
User                    API                     Database
  │                      │                         │
  │  POST /auth/register │                         │
  │─────────────────────>│                         │
  │                      │  Validate password      │
  │                      │  Hash password          │
  │                      │  Create user            │
  │                      │────────────────────────>│
  │                      │                         │
  │  <─────────────────  │                         │
  │  { user, tokens }    │                         │
```

**Request**:
```bash
curl -X POST http://localhost:8000/api/v1/auth/register \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\n    \"username\": \"alice\",\n    \"email\": \"alice@example.com\",\n    \"password\": \"SecurePass123!\",\n    \"full_name\": \"Alice Smith\"\n  }'\n```

**Response**:
```json\n{\n  \"user\": {\n    \"id\": \"user_123\",\n    \"username\": \"alice\",\n    \"email\": \"alice@example.com\",\n    \"role\": \"user\"\n  },\n  \"access_token\": \"eyJ...\",\n  \"refresh_token\": \"eyJ...\",\n  \"expires_in\": 900\n}\n```

#### Login Flow

```
User                    API                     Database
  │                      │                         │
  │  POST /auth/login    │                         │
  │─────────────────────>│                         │
  │                      │  Find user              │
  │                      │────────────────────────>│\n  │                      │  Verify password        │\n  │                      │  Check lockout          │\n  │                      │  Create session         │\n  │                      │────────────────────────>│\n  │                      │                         │\n  │  <─────────────────  │                         │\n  │  { tokens }          │                         │\n```
